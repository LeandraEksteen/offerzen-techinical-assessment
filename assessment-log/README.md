# Assessment log

Working notes kept while completing this take-home. Optional reading for reviewers.

- [`PROMPTS.md`](PROMPTS.md): every prompt given to the AI coding assistant, verbatim, in order. A summary goes at the top once the work is done.
- [`DECISIONS.md`](DECISIONS.md): numbered decisions (process and technical), with context and rationale.
- [`spec/`](spec/): the approved spec (`spec.md`, `requirements.yaml`) the tickets are built from.
- [`tickets/`](tickets/): `EPIC-1` and `TKT-1` to `TKT-12`, one groomed ticket per piece of work. Each PR links to its ticket.

Ground rules agreed up front:

1. No commits or PRs without the author's explicit permission.
2. No assumptions: unclear points are put to the author to decide.
3. Work is ticketed as if on a real team: one epic, one groomed ticket per task, one PR per ticket.
